# 10 · 6 周备考计划

> 按社区共识的 E5 备考周期（4–6 周，每天 1–2 小时）排布。核心原则：**50% 时间在输出（做题/mock/复盘），输入只占 30%**。可以压缩到 4 周（每周强度 ×1.5），不建议低于 4 周。

## 总览

```
周 1    认知与框架        评分标准内化 + 框架练到肌肉记忆 + 数字表
周 2    构件与入门题      构件速过 + Q1–Q3（Easy 三连）
周 3    核心真题 Ⅰ        Q4–Q5 + 第一次真人 mock
周 4    核心真题 Ⅱ        Q6–Q8 + 第二次 mock + 案例研究启动
周 5    深度与迁移        母题归纳 + 盲做新题 + 第三次 mock
周 6    冲刺              公司风格校准 + 弱点专项 + 复盘卡片
```

## 第 1 周 · 认知与框架

**目标**：知道考什么、怎么走场，还没碰具体题。

- [ ] 读 [01](01-what-is-system-design.md)、[02](02-e5-senior-expectations.md)——把四维 rubric 抄在自己桌上
- [ ] 读 [03](03-delivery-framework.md)，用 1 道简单题（如"设计 Pastebin"）**只练流程**，不看深度，录像
- [ ] 背 [04](04-estimation-numbers.md) 的三张表（延迟 / 可用性 / 单机容量），每天口算 2 个场景
- [ ] 周末自检：不看资料说出六阶段时间预算 + 每阶段一句话目标

**本周产出**：一段 45 分钟盲做录像 + 一张自己手写的 rubric。

## 第 2 周 · 构件与入门题

- [ ] [05](05-building-blocks.md) 过一遍，每个构件做一张三列表（方案/备选/代价）
- [ ] Q1 短链、Q2 限流、Q3 Top-K，**严格按 06 总览的 5 步练习法**（盲做 → 对照 → cheat sheet → 3 天后重做 → 讲给别人）
- [ ] 配套看 ByteByteGo 对应构件的动画（每集 ≤10 分钟，看完必须能复述）

**本周产出**：3 道题的 cheat sheet + 三张构件 trade-off 表。

## 第 3 周 · 核心真题 Ⅰ + 第一次 mock

- [ ] Q4 聊天、Q5 Feed，同样 5 步法
- [ ] **第一次真人 mock**（interviewing.io 或朋友）——预期会被虐，重点记录：时间失控点、卡壳点、被 hint 的次数
- [ ] Mock 复盘写进 `mock-log.md`：每个失误归类（流程 / 知识 / 深度）

**本周产出**：2 道题 + 第一份 mock 复盘。

## 第 4 周 · 核心真题 Ⅱ + 案例研究启动

- [ ] Q6 消息队列、Q7 票务、Q8 点击聚合
- [ ] DDIA 第 5、6、9 章（每天 30–40 页）
- [ ] 每天读 1 个案例（[07](07-real-systems-case-studies.md) 的清单），一行笔记进 `cases.md`
- [ ] 第二次 mock

**本周产出**：3 道题 + 7 条案例笔记 + 第二份 mock 复盘。

## 第 5 周 · 深度与迁移（E5 的关键一周）

**目标**：从"会这 8 道题"变成"会所有题"。

- [ ] **母题归纳**（[06 总览](06-classic-questions-overview.md) §2）：对每道做过的题标注母题，写出该母题的通用深挖三件套
- [ ] **盲做 2 道没准备过的题**（Hello Interview 题库随机挑，如 Distributed Cache、Dropbox、Typeahead Suggestion）——检验迁移能力，这是本周唯一 KPI
- [ ] 第三次 mock，这次重点观察自己有没有"驱动讨论"
- [ ] 弱点专项：从三份 mock 复盘里找出现次数 ≥2 的问题，集中补

**本周产出**：母题对照表 + 2 道陌生题的完整盲做录像。

## 第 6 周 · 冲刺

- [ ] 读 [08](08-company-guides.md)，针对目标公司调整表达重心
- [ ] 每天中午 15 分钟"电梯版"练习：随机抽 1 题，60–90 秒讲完核心 trade-off
- [ ] 过一遍所有 cheat sheet 和 mock-log，**只复习失败点，不学新东西**
- [ ] 面前 48 小时：不做新题、不看新资源；只做一次轻松的全流程 walkthrough + 睡够

## 时间不够的 4 周压缩版

砍法：第 2 周并入第 1 周（构件只看 05 章文字版，跳过视频）；Q6 和 Q8 二选一；mock 从 3 次减到 2 次（**mock 不能再减**，它是备考的最大杠杆）。

## Mock Log 模板

```markdown
## Mock #N — 日期 / 平台 / 题目
- 总体感觉（1–5）：
- 时间控制：哪个阶段超时了？
- 主动驱动了吗？（有几处是我提议方向？）
- 被 hint 的次数和内容：
- 卡壳瞬间（题干 + 我当时的处理）：
- 归类：□流程 □知识 □深度 □沟通
- 下次要改的一件事（只选一件）：
```

## 每日节奏建议（在职版）

```
通勤 20 min：口算练习 / YouTube 构件视频 / 案例笔记
晚上 60–90 min：当前周的主任务（真题 or mock）
周末 2–3 h：盲做 + 录像回看 + 重做
```

## 最后一页（打印贴墙上）

1. 先问需求再动笔——**需求写上白板**
2. 每个数字后面跟一句"所以……"
3. 每个组件三段式：是什么 / 为什么 / 坏了怎么办
4. 主动提议深挖点，和面试官协商
5. 被纠偏 = 收到礼物，立刻调头
6. 留最后 5 分钟收尾：瓶颈 / 监控 / 未覆盖
7. 卡壳就说出来："我在 A 和 B 之间犹豫……"
8. **你是在做 design review，不是在被审问。**
